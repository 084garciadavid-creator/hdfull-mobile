# HDFull Mobile

Aplicación Android nativa en Kotlin/Jetpack Compose.

## Corrección incluida

La versión actual incluye mejoras en la extracción de enlaces de vídeo: transferencia de cookies al WebView, detección de Cloudflare, enlaces relativos, iframes, atributos `data-*`, `onclick` y eliminación de duplicados.

> El proyecto requiere Android Studio/Gradle y las dependencias definidas en `app/build.gradle.kts`.
